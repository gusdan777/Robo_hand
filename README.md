# Запуск сайта

## Шаг 1 — Открыть папку проекта

1. Скачайте `main.py` с страницы проекта
2. Откройте VS Code
3. Нажмите **File → Open Folder**
4. Выберите папку где лежит `main.py`

---

## Шаг 2 — Открыть терминал

В VS Code нажми `` Ctrl + ` ``

Внизу откроется встроенный терминал.

---

## Шаг 3 — Установить Flask

В терминале выполните:

```bash
pip install flask
```

Это нужно сделать только один раз.

---

## Шаг 4 — Запустить сервер

```bash
python main.py
```
---

## Шаг 5 — Открыть сайт в браузере

Перейди по адресу:

```
http://localhost:5000/main.py
```

---

## Управление статусом

Через кнопку на сайте, или напрямую в адресной строке браузера:

```
http://localhost:5000/main.py?knopka=on
http://localhost:5000/main.py?knopka=off
```

---

## Остановить сервер

В терминале VS Code нажми `Ctrl + C`.

---
