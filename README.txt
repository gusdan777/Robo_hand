Базовый URL
https://gusdan777.github.io/Robo_hand/status/

Команды
Включить - /knopka_on
Выключить /knopka_off

Как использовать
По умолчанию на экране надпись status: off
Использум команды следующим образом:
https://gusdan777.github.io/Robo_hand/status/knopka_on - на экране появляется надпись status: on
https://gusdan777.github.io/Robo_hand/status/knopka_off - на экране появляется надпись status: off
